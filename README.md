# Pokélab 허브 페이지 (새 프로젝트로 이사용)

이 폴더는 "오늘의 포켓몬은 뭘까요" 프로젝트에서 분리해서 **별도 프로젝트/저장소**로 옮기기 위해 만든 패키지입니다.

## 파일
- `hub.html` — Pokélab 허브 페이지 본체. 새 프로젝트(저장소)에서는 이 파일을 **`index.html`로 이름을 바꿔서** 저장소 루트에 두면 GitHub Pages 배포 시 바로 메인 페이지로 뜹니다. (원래 퀴즈 프로젝트 쪽 `index.html`과 이름이 겹치면 안 되기 때문에 여기서는 `hub.html`로 임시 저장했습니다.)

## 디자인
- 흰 배경 + 그레이/블랙, 심플·모던
- 모바일 최적화: 세로로 긴 레이아웃 (로고 상단 중앙 → 버튼 2개 → 맨 아래 작은 로그인 버튼)
- PC에서도 최대폭 440px 중앙 정렬이라 좌우 여백이 넓게 유지됨

## 서브페이지 링크 (절대경로, 다른 저장소이므로)
- "오늘의 포켓몬은 뭘까요" → `https://iruroda.github.io/todayspokemon`
- "Pokémon Pokopia" → `https://iruroda.github.io/pokopia`

두 링크 모두 같은 탭에서 이동하도록 되어 있습니다(허브도 하나의 사이트처럼 느껴지게 하려는 의도). URL이 바뀌면 `hub.html`의 `<nav>` 안 `href` 두 곳만 고치면 됩니다.

## 로그인 (Firebase 계정 공유 — 중요)
"오늘의 포켓몬은 뭘까요" 퀴즈 페이지와 **완전히 동일한 Firebase 프로젝트**(`todayspokemon-ef9c0`)를 그대로 사용합니다. `hub.html` 안의 `firebase.initializeApp({...})` 설정값을 절대 바꾸지 마세요 — 바꾸면 계정이 분리되어 로그인 상태가 공유되지 않습니다.

같은 아이디→이메일 변환 함수(`idToEmail`)와 같은 localStorage 키(`psq2curuser`)를 쓰기 때문에, 허브/퀴즈/향후 추가될 서브페이지가 전부 **같은 GitHub Pages 계정 도메인(`iruroda.github.io`) 아래**에 있기만 하면(레포는 달라도 상관없음 — 오리진은 도메인 기준이라 경로/레포가 달라도 동일 오리진으로 취급됨) 로그인·로그아웃 상태가 자동으로 공유됩니다.
- 허브에서 로그인 → 퀴즈 페이지로 이동해도 로그인 상태 유지
- 퀴즈 페이지(서브페이지)에서 로그아웃 → 허브로 돌아와도 로그아웃 상태로 표시
- 이는 `firebase.auth()`의 기본 로컬 세션(오리진 단위 저장)과, 모든 페이지가 공통으로 참조하는 `psq2curuser` localStorage 키, 그리고 각 페이지가 로드 시 `fbAuth.onAuthStateChanged`로 최신 로그인 상태를 다시 읽어오는 구조 덕분에 별도 작업 없이 동작합니다.
- 단, Firestore 기록 동기화(도감 진행도 저장)는 퀴즈 페이지에만 있고 허브에는 없습니다(허브는 로그인 상태 표시만 담당). 필요하면 추가 가능.

## 이어서 작업할 때 참고
- 앞으로 서브페이지가 늘어나면(예: Pokémon Pokopia 완성 등) 허브의 `<nav>` 블록에 같은 스타일(`.nav-btn`)로 버튼만 추가하면 됩니다.
- 로고("Pokélab") 자리, 버튼 스타일, 로그인 모달 스타일 등은 전부 `hub.html` 안 `<style>` 블록 상단에 있습니다.
